# 已知「有开关/选项但 v0.1.2 不产生效果」的设置

用户问题（m02706）：删除智能动感模式的开关，并总结其他**有开关但未生效**的功能。
本文件是代码层面核对后的清单。v0.1.2 只删除了「智能动感模式」开关，其余保留（部分是为与 Folia 设置页布局一致），
但下列项目在 v0.1.2 中没有数据来源或没有映射到渲染器，因此不会产生视觉变化。

## A. 缺少数据/模型，无法生效

| 位置 | 控件 | 原因 |
| --- | --- | --- |
| ~~歌词动画~~ | ~~智能动感模式~~ | **v0.1.2 已移除**。Folia 的节拍检测模型（beat_this / htdemucs，WebGPU）不在 WebView bundle 中，也没有节拍事件流。 |
| 歌词动画 → 动感效果 | 推镜裂光（开关 + 强度） | 同上：效果由 `beatImpact` / `downbeatImpact` 驱动，没有节拍事件时始终为 0，不触发。 |
| 字幕 | 罗马音模式 | 插件不提供罗马音数据。 |
| 字幕 | 显示和声字幕 / 和声字幕背景 | 插件不提供 harmony/和声数据；`showHarmonySubtitle` 已传入 config 但无内容可显示。 |
| 字幕 | 字幕内容模式（部分选项） | 依赖翻译/罗马音数据；有翻译时「翻译」模式生效。 |

## B. WebView 沙箱/上传能力未实现，无法生效

| 位置 | 控件 | 原因 |
| --- | --- | --- |
| 字体 | 自定义字体文件选择、系统字体选择 | 页面无法读取本地字体文件；v0.1.2 使用内置字体栈（MiSans/系统字体）。 |
| 背景 | 自定义图片/上传背景（url 模式）、本地文件选择 | 插件只推送内置背景模式（common/latent/monet/nomand/sora 等），不提供本地图片。 |
| 字体/各样式参数 | 凝彩图层图片、莫奈人像图片、群唱自定义头像/表情包 | `ObsBrowserSourceConfig` 有对应 data-URL 字段，但本插件没有上传/选择入口（上传类控件为存根）。 |

## C. 配置未映射到 `ObsBrowserSourceConfig`（显示但渲染器不读取）

| 位置 | 控件 | 原因 |
| --- | --- | --- |
| 字体 | 字体族（无衬线/衬线/等宽/自定义）、字重 | `deriveTheme()` 固定 `fontStyle: 'sans'`，config 中没有字体族/字重字段。 |
| 字幕 | 字幕字体族/字重/系统字体、字幕字体跟随歌词 | 同上，config 未映射。 |
| 字体/字幕 | 字号 | **生效**：映射为 `lyricsFontScale` / `subtitleFontScale`。 |
| 背景 | 背景亮度/模糊等内置背景参数 | **生效**：映射为 `background` 对象。 |
| 样式参数 | 纹理分辨率、镜头运动强度、文字动势、背景短线密度、各样式 tuning 开关 | **生效**：映射为 `visualizerTunings`（按当前 style 的 `*_tuning`）。 |
| 字幕 | 字幕不透明度、字幕背景、即将歌词模糊、隐藏翻译字幕 | **生效**：映射到 config 对应字段（有数据时）。 |

## D. 说明

- 这些选项保留，是为了让设置页与 Folia 原版布局一致，同时方便后续版本补齐（例如把节拍检测移入原生宿主、
  增加本地字体/图片上传）。在补齐之前，改动它们不会影响全屏画面。
- 真正的「封面取色」在 v0.1.2 已修复，见 [verification-v0.1.2.md](verification-v0.1.2.md)。
- 如果你希望某些无效开关直接隐藏（而不是保留），可以在 issue 中按条目反馈。
