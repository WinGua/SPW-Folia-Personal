# spw-folia v0.1.9 — 鼠标穿透开关（透明时也能操作桌面）

v0.1.8 让透明播放页里的控件重新可点，但整窗口都在吃鼠标：透明时想点桌面上的东西，只能先退出透明。
v0.1.9 补上 **「鼠标穿透（操作桌面）」** 开关，并删掉左下角那个控制 chip —— 现在右下角圆钮和右上角
齿轮在任何状态下都能点，不再需要额外的浮标窗口。

## 更新内容

- **面板新增「鼠标穿透（操作桌面）」** — 右下角金色圆钮打开的面板里，第二行开关；只有透明背景开启时
  出现。默认关闭 = 透明窗口仍可点页面（v0.1.8 行为）；打开后点击落向桌面/其它窗口，
  但右下角圆钮、右上角齿轮、它们打开的面板与设置页仍然可点。
- **状态持久化** — 新字段 `mousePassthrough` 存进设置树，与其它设置一起持久化；关闭透明背景时
  自动复位成 `false`，下次进入透明不会莫名其妙穿透。
- **删除左下角 chip** — 宿主 `TransparencyBadge` 及其显示/隐藏逻辑移除，透明模式下画面更干净。
- **热区转发机制** — 页面把两个浮标、打开中的面板、设置整页的矩形报给宿主；透明窗口上的不可见
  输入捕获窗口只在热区内转发鼠标，热区外（穿透开启时）隐藏自己、合成一次真实左键、220 ms 后恢复。
- **逃生通道保留** — **Ctrl+Alt+B**（备用 Ctrl+Alt+Y / Ctrl+Alt+P / Ctrl+Alt+Shift+B）仍然双向切换透明，
  退出透明会自动释放鼠标穿透。

## 验证

- 页面+宿主级 9 项全部通过：面板开关互切、穿透点击落桌面（`transparency passthrough=click at=1600,560`）、
  穿透下圆钮/齿轮/设置页返回键可点、热键退出后 `mode=off` + `passthrough=off`。
- 真机（SPW 1.19 + 0.1.9）：透明下两行开关可操作、点桌面生效、齿轮打开设置页、热键恢复不透明。
- 细节见 [verification-v0.1.9.md](verification-v0.1.9.md)、[live-transparency.md](live-transparency.md)。

## 安装 / 升级

1. 关闭 Salt Player for Windows。
2. 打开 mod 管理器，删除旧版 `spw-folia`，导入 `spw-folia-0.1.9.spmod`。
3. 授予 `class-transform` 与 `library-read` 两项权限。
4. 重启 SPW，`更多 → Folia`，右下角圆钮 → 打开「播放页透明背景」；需要操作桌面时再打开
   「鼠标穿透（操作桌面）」。

## 已知限制

- 穿透点击是「隐藏捕获窗口 → 合成一次左键 → 恢复」的时序（约 220 ms），极快连点可能丢一次。
- 键色透明仍是 `rgb(255,0,255)` 色键方案：页面若恰好绘制该纯色会被挖空（当前主题不会）。
- 仅主屏全屏；多屏选择未实现。
